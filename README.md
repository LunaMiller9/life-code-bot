# Life Code Bot

Телеграм-бот: считает Цифру Я, проверяет подписку на канал Life Code,
выдаёт карточку с расшифровкой цифры.

## Что внутри
- bot.py — код бота
- images/ — 9 карточек-картинок (по одной на каждую цифру)
- requirements.txt — список библиотек
- Procfile — файл для Railway (говорит, как запускать бота)

## Настройка
Токен бота передаётся через переменную окружения BOT_TOKEN
(смотри инструкцию по деплою на Railway — там это поле называется Variables).

## Локальный запуск (для разработчика)
pip install -r requirements.txt
export BOT_TOKEN=токен_бота
python bot.py
